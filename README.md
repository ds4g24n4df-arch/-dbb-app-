# 店帮帮AI 安卓 App —— 云端编译说明（不用在自己电脑装任何软件）

这个文件夹是**一个完整的安卓工程**（只包含 App 需要的东西，和网页那套互不影响）。
把它传到 GitHub，GitHub 会**免费替你编译**，编好的安装包你下载下来装到手机就行。

> 这个 App 装的是你现有的线上语音台（同一个账号、同一份配置），另外多做两件事：
> ① 后台常驻（锁屏、切到抖音也不被系统回收）；② 读屏采集抖音公屏（点赞/关注/弹幕）。
> **它不会改动你现有的网页和服务，一个字节都不改。**

---

## 你需要准备

- 一个 **GitHub 账号**（免费注册：https://github.com/signup ）
- 一个能上 GitHub 的网络
- 一台手机（安卓）

整个过程不用命令行、不用装软件，全程在网页上点。

---

## 第一步：把这份文件夹传到 GitHub

1. 登录 GitHub，右上角 **+** → **New repository**
2. **Repository name** 填 `dbb-app` → 下面选 **Private**（私有，别人看不到）→ 点 **Create repository**
3. 在新仓库页面点 **uploading an existing file**（或 **Add file → Upload files**）
4. 把**这个文件夹里的所有内容**（`app`、`gradle`、`gradlew`、`gradlew.bat`、`settings.gradle.kts`、`build.gradle.kts`、`gradle.properties`、`app.properties`、`.github`）**一起拖进**网页的上传框里 →
   页面底部点 **Commit changes**
   - ⚠️ **务必确认 `.github` 这个文件夹也传上去了**（它是编译说明，没有它 GitHub 不会自动编译）。
     如果拖拽时漏了它，用这个办法补：仓库页面 **Add file → Create new file**，文件名一栏直接输入
     `.github/workflows/build-apk.yml`（斜杠会自动建文件夹），把工程里同名文件的内容整段粘进去 → Commit。

## 第二步：等它自动编译

1. 传上去之后，点仓库上方的 **Actions** 页签
2. 会看到一条正在跑的任务（名字叫「编译安卓安装包」），点进去
3. 等它变绿（第一次 3~8 分钟，要下载安卓依赖；之后快很多）
4. 如果它变红（失败）：点进去，把红色的那一段（前 30 行左右）复制发我，我来改

## 第三步：下载安装包

1. 在那次运行页面**拉到最下面**，找到 **Artifacts** → 点 **dbb-app-debug** 下载（是个 zip）
2. 解压 zip，里面就是 **app-debug.apk**

## 第四步：装到手机上

1. 把这个 apk 传到手机（微信发给自己 → 在手机上下载；或数据线复制）
   - 别在微信里直接点开安装（微信会拦）。用「文件」或浏览器打开它
2. 手机提示「**未知来源 / 有风险**」→ 点**允许**、继续安装（侧载 App 都会这样提示）
3. 装好后桌面上会出现 **店帮帮AI**

## 第五步：手机上开一次权限（就一次）

打开 App，会直接进你的语音台。然后给它开这三样：

1. **通知**：第一次打开会弹，点允许；
2. **无障碍**（读公屏靠它）：App 里「配置 → 弹幕接入」页上有一张 **App 采集**卡，
   点「**去开启无障碍权限**」→ 在系统页面里找到 **店帮帮AI** → 打开开关 → 回到 App；
3. **电池不受限制**：同一张卡上点「**电池不受限制**」→ 允许（防止锁屏被系统杀掉）。

> ⚠️ **强烈建议先在 App 里用手机号注册/登录**，然后再长期使用。
> 因为手机上的账号默认跟"这台设备"绑定，卸载重装会变成新账号、配置就没了；
> 注册后账号跟着手机号走，换设备、重装都能找回。

## 以后改东西怎么重新编

- 改**话术、音色、规则、界面**：**不用重新编包** —— 那些都在线上网页里，App 打开时自动就是最新的。
- 改**App 本身**（图标、名字、采集逻辑、权限）：把新代码传上去 → Actions 会自己再编一次 → 重新下载安装包覆盖安装。
- 覆盖安装能成功的前提是**签名一致**：这个工作流把签名钥匙（`signing/`）缓存住了，
  所以从第二次开始签名是稳定的，直接覆盖装就行。**如果哪天提示"签名不一致，请先卸载"**，
  那就是缓存被清了（或换了仓库），只能先卸载旧版再装 —— 卸载会清掉手机上那份本地数据，
  所以你更需要提前用手机号注册登录。

## 想改 App 名 / 图标 / 版本号

都在 `app.properties` 这一个文件里（不用碰代码）：

| 改什么 | 在哪 |
|---|---|
| App 名字（桌面图标下面那行字） | `appName=店帮帮AI` |
| 版本号 | 每次要给别人装新版前，把 `versionCode` 加 1 |
| 打开的网址 | `app/src/main/res/values/strings.xml` 里的 `start_url` |

图标在 `app/src/main/res/drawable/ic_launcher_background.xml`（底色）和
`ic_launcher_foreground.xml`（图案）。

## 常见问题

**Q：一定要传 GitHub 吗？别人能看到我的代码吗？**
A：新建仓库时选 **Private**，就只有你自己能看到。

**Q：编译失败了怎么办？**
A：把那次运行里红色的日志发我（前 30 行就够），我改完你重新上传就行。

**Q：这个 App 会动我现有的网页/服务吗？**
A：不会。它只是"装在手机上的一个入口 + 一个采集器"，调的是你现有的线上接口，
跟现在手机上用浏览器打开是同一份账号和数据。

**Q：苹果手机能装吗？**
A：不能。这个安装包是安卓的；而且苹果系统不允许读别的 App 的界面，采集这条路在 iPhone 上走不通。
